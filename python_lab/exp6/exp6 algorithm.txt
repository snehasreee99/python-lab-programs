Experiment 6: Demonstrate Dictionary & Related Functions in Python

Algorithm:
1. Start.
2. Create a dictionary with key-value pairs.
3. Display the dictionary and find its length using len().
4. Access a value using its key, and using get().
5. Add a new key-value pair or update an existing one by assignment.
6. Remove a key-value pair using pop(), popitem(), or del.
7. Retrieve all keys using keys(), all values using values(), and all key-value pairs using items().
8. Check if a key exists using the in operator.
9. Update the dictionary with another dictionary using update().
10. Create a copy of the dictionary using copy().
11. Iterate over the dictionary using a for loop to display keys and values.
12. Create a dictionary using dictionary comprehension.
13. Clear all elements using clear().
14. Display the results after each operation.
15. Stop.
